# Study Time

日ごとの勉強時間を記録するPWA（Progressive Web App）です。

🔗 https://hkbbbn-3.github.io/study-time-app/

## 主な機能
- 今日の目標達成率をリング表示、連続達成日数（ストリーク）、レベル表示
- 月曜始まりのカレンダーで、日ごとの記録・達成状況を確認
- 科目別に勉強時間を記録（科目の名前・色は後から編集可能）
- 平日／休日ごとに目標時間を設定
- ダークモード対応
- バックアップの書き出し（JSON）・読み込み、CSV書き出し
- ホーム画面に追加してアプリのように使える（PWA）
- キーボード操作・スクリーンリーダーに対応

## データについて
記録はすべて**この端末のブラウザの中だけ**に保存されます（サーバーには送信されません）。機種変更やブラウザのデータ削除で消えてしまうため、設定画面から時々バックアップを書き出しておくことをおすすめします。

## 技術構成
ビルド不要のバニラHTML/CSS/JavaScriptのみで作られています。GitHub Pagesでそのまま公開しています。
